Goal: the game is playable in Spanish. Add a language choice (EN/ES) to the main
menu and to Settings, persist it in `save.settings.lang`, apply it at startup
via `applySettings`, and translate everything the player reads.

Rules:
- UI chrome (menus, HUD, garage, results, popups, touch labels) goes through
  `t('key')`; EN reference tables in `src/i18n/en*.ts` area files, ES mirrors in
  `src/i18n/es*.ts`, same keys.
- Long content (story, dialogue, radio, barks, tips, lore, upgrade advice, car
  and track descriptions, part names/descriptions) stays English in `src/data`
  and is translated at display time through `tx(english)`; ES content lives in
  `src/i18n/esContent*.ts` keyed by the exact English text.
- Character names, car model names and fictional brand names are NOT translated.
- `{param}` placeholders must appear identically in both languages.
- No edit to src/types, src/core, src/camera, src/main.ts, physics/carController.
- Files under 220 lines; `import type` for types; no enum/namespace/param props.
- `tests/i18n-check.mts` enforces EN/ES key parity and 100% ES content coverage.
