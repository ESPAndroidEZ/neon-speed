# Audio credits

Engine sounds: recorded loops by default (Settings > Engine sound: Recordings / Synth). Every loop in
public/audio/engines/<car>/ is a 0.5-1.5 s steady-rpm loop cut, pitch-flattened, crossfaded and level-matched from the
recordings below (tools and exact cut list: scripts/engine-loops/). The in-game credit text is
public/audio/engines/CREDITS.txt (shown in Settings > Sound credits; kept outside the bundle so the brand-safe build
never rewrites it). Turbo whistle, blow-off and pops stay procedural (LOCKED). Rivals keep the per-car synth voices.
