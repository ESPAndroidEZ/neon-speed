# Installing on iPhone and Android

Three routes, from easiest to most native. All use the same Vite build.

## 1. Install from the browser (PWA, works today, no SDK)
`npm run dev` serves on the LAN (http://<pc-ip>:5173). For a real install host the build over HTTPS:
`npm run build && npx vite preview --host` (or any static host: Netlify, Cloudflare Pages, GitHub Pages).
- **iPhone (Safari):** Share, Add to Home Screen. Opens fullscreen, landscape, with the app icon.
- **Android (Chrome):** menu, Install app. Works offline after the first visit (`public/sw.js`).
Files: `public/manifest.webmanifest`, `public/sw.js`, `public/icons/*` (generated by `npm run icons`).

## 2. Android app (Capacitor, APK / Play Store)
Needs Android Studio (JDK 17 + Android SDK). The project `android/` is already generated.
```
npm run mobile:android      # builds the web app, syncs it into android/, opens Android Studio
```
Press Run on a device (USB debugging) or Build > Build Bundle(s) / APK(s). Landscape is locked in `AndroidManifest.xml`.

## 3. iOS app (Capacitor, TestFlight / App Store)
Needs a Mac with Xcode and a free or paid Apple developer account. The project `ios/` is already generated.
```
npm run mobile:ios          # builds, syncs, opens Xcode (run once: cd ios/App && pod install)
```
Select your team under Signing, choose the iPhone, press Run. Landscape only, status bar hidden (`Info.plist`).

## After changing the game
`npm run mobile:sync` copies the new build into both native projects. Icons: edit `scripts/make-icons.mjs`, run `npm run icons`.
App id `com.racersblood.game` and the name are in `capacitor.config.ts`.

## Notes
- Touch controls appear automatically on `pointer: coarse` devices (`ui/touchControls`); graphics start on the saved tier, auto quality lowers it if the frame rate drops.
- Haptics and the splash screen plugin are not added yet (phase 6).
