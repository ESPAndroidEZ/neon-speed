# Installing on iPhone and Android

Three routes, from easiest to most native. All use the same Vite build.

## 1. Install from the browser (PWA, works today, no SDK)
`npm run dev` serves on the LAN (http://<pc-ip>:5173). On WSL2 run `scripts/phone-access.ps1` once in an admin PowerShell (port forward + firewall; re-run after a reboot). For a real install host the build over HTTPS:
`npm run build && npx vite preview --host` (or any static host: Netlify, Cloudflare Pages, GitHub Pages).
- **iPhone (Safari):** Share, Add to Home Screen. Opens fullscreen, landscape, with the app icon.
- **Android (Chrome):** menu, Install app. Works offline after the first visit (`public/sw.js`).
Files: `public/manifest.webmanifest`, `public/sw.js`, `public/icons/*` (generated by `npm run icons`).

## 2. Android app (Capacitor, APK / Play Store)
Needs Android Studio (JDK 17 + Android SDK). The project `android/` is already generated.
```
npm run mobile:android      # builds the web app, syncs it into android/, opens Android Studio
```
Press Run on a device (USB debugging) or Build > Build Bundle(s) / APK(s). Landscape is locked in `AndroidManifest.xml`.

## 3. iOS app (Capacitor, TestFlight / App Store)
Needs a Mac with Xcode and a free or paid Apple developer account. The project `ios/` is already generated.
```
npm run mobile:ios          # builds, syncs, opens Xcode (run once: cd ios/App && pod install)
```
Select your team under Signing, choose the iPhone, press Run. Landscape only, status bar hidden (`Info.plist`).

## After changing the game
`npm run mobile:sync` copies the new build into both native projects. Icons: brand art lives in `resources/brand/` (`website-icon.png` = wordmark only, used for the browser tab icons `public/icons/favicon-32/48.png`; `app-icon-cartoon.png` = cartoon car, used for the larger browser icons `favicon-car-192/512.png`; `app-icon.png` = geometric car, used for every phone icon: PWA, apple-touch, maskable, Android mipmaps and adaptive foreground, iOS 1024). Replace those PNGs and run `npm run icons`; the script strips the white outside the rounded corners and fills full-bleed squares for the launchers.
App id `com.racersblood.game` and the name are in `capacitor.config.ts`.

## Notes
- Phone controls (Settings > Screen and controls, and a one-time chooser on the first start): **Tilt** (turn the phone like a wheel; auto gas, big BRAKE left, NITRO / HANDBRAKE / pause right; calibrate, sensitivity, full-lock angle, invert, manual gas), **Touch wheel** (drag-steer left, GAS / BRAKE right; the approved session-8 layout) or **Buttons** (left/right arrows). Code: `input/tiltMap` (pure maths, tests/tilt-check), `input/tiltInput`, `input/controlPrefs` (own storage key `rb-controls`), `ui/touchControls` + `ui/touchButton`, `ui/controlsOnboard`.
- iOS asks for motion access from a tap ("Enable tilt" / choosing Tilt); denial falls back to the touch wheel. Motion sensors need HTTPS on iOS.
- Full screen: HUD icon, pause menu and Settings (`core/fullscreen`, `ui/fullscreenButton`). iPhone Safari has no Fullscreen API: the button becomes "Add to Home Screen" with a one-time hint. The app (Capacitor) hides the status bar instead. Entering full screen tries to lock landscape; a wake lock keeps the screen on while racing (`core/wakeLock`).
- Responsive: canvas follows the visual viewport (`core/viewport`), the chase camera widens and pulls back in portrait and caps the horizontal view on 32:9 (`camera/aspectFrame`), portrait shows a small "rotate your phone" hint. Checked by `npm run viewport` (10 viewports).
- Haptics: `ui/haptics` (Capacitor Haptics in the app, navigator.vibrate on Android browsers).

## Install button (2026-11-18)
Main menu shows "Install app" when the page is not already installed and not inside the native shell (`core/install.ts`, `ui/installButton.ts`). Android Chrome / Edge / Samsung: the `beforeinstallprompt` event is kept and the button opens the browser's install dialog (the prompt only exists on the production build, which registers the service worker). iPhone / iPad Safari has no install API: the button shows a how-to card (Share > Add to Home Screen). Android browsers without the prompt get a menu how-to. Desktop without the prompt shows nothing. Test: `tests/install-check.mts`.
