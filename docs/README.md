# Documentation index

Start with the file for your role. Everything is kept up to date at every checkpoint.

**For the owner (Carlos)**
- `owner-guide.md`: what the game is, how it fits together, a cheat sheet of commands, decisions, risks, what is not verified.
- `changelog.md`: what changed, by date, in plain language.
- `roadmap-online.md`: the plan for server, leaderboards, own lobby and Redis.
- `master-plan.md`: the living list of big jobs (music, server settings, leaderboards, online lobby, open world) with the status of every item.
- `prompts/everything.md`: the prompt to paste into a new session to start (and, later, resume) all of it. `prompts/server-to-code.md` is the older, smaller version.

**For Claude and Qwen**
- `skills.md`: where things live in the code, playbooks, server facts, gotchas. Read first.
- `handoff.md`: live status, Done and Next, one log line per session.
- `code-map.md`: one line per source file (generated by `npm run map`, do not edit).
- `story.md`: story canon, cinematics. `qa-report.md`: visual findings. `plan.md`, `architecture.md`: design background.
- `tasks/`: Qwen task files. `inbox/`: owner notes. Other files (`art-direction.md`, `ui-style.md`, `mobile.md`, `release.md`, `perf.md`, `audio-*.md`, `car-data.md`): topic references.

**The rule:** after every change, update the affected documents in the same step; end every session with `/checkpoint`.
